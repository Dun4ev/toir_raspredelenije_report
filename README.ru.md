# Менеджер распределения PDF-отчетов ТОиР

[English](README.md) | [Русский](README.ru.md)

Windows-ориентированная утилита на Python для распределения PDF-отчетов ТОиР по целевым каталогам, создания архивов проектов и записи всех операций в журналы JSONL. В проект входят настольный интерфейс Tkinter и консольный отчет по журналам.

> [!IMPORTANT]
> Каждый отчет должен находиться в отдельной подпапке входного каталога. Если PDF-файлы обнаружены непосредственно в корне INBOX, обработка останавливается с предупреждением.

## Интерфейс

Интерфейс поддерживает английский и русский языки. Переключатель находится в правом верхнем углу; выбранный язык сохраняется для следующего запуска.

### Распределение

Укажите каталоги INBOX и назначений, выберите фильтр части `CS`/`LP`, включите нужные направления и запустите распределение.

### Журналы

Просматривайте предыдущие запуски, статусы операций и пути, открывайте целевые каталоги или удаляйте старые журналы.

![Вкладка журналов](<assets/image copy.png>)

## Возможности

- Рекурсивный поиск проектных каталогов с файлами `_All.pdf`.
- Разбор атрибутов отчета из имени файла.
- Фильтрация по `CS`, `LP` или совместному режиму `CS/LP`.
- Копирование отчетов в NOTES, TRA_GST, TRA_SUB_APP и итоговую структуру PDF.
- Создание ZIP-архивов исходных проектных каталогов в структуре `Native`.
- Потокобезопасные журналы операций JSONL для UI и CLI.
- Сохранение путей, флагов назначений, фильтра части и языка интерфейса.
- Запрет запуска UI при `APP_HEADLESS=1`.

## Требования

- Python 3.10 или новее.
- `openpyxl` для чтения `Template/TZ_glob.xlsx`.
- Tkinter, который входит в стандартную поставку Python для Windows.

Создание и активация виртуального окружения:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install openpyxl
```

Для разработки и тестирования:

```powershell
python -m pip install pytest ruff black mypy types-openpyxl
```

## Быстрый старт

Запуск настольного приложения:

```powershell
python run_ui.py --base-dir logs/dispatch
```

Прямой запуск конвейера распределения:

```powershell
python toir_raspredelenije.py
```

Переопределение INBOX для текущей сессии PowerShell:

```powershell
$env:TOIR_INBOX_DIR = "D:\Reports\00_Inbox"
python toir_raspredelenije.py
```

Вывод сводки журналов в JSON:

```powershell
$env:PYTHONPATH = "src"
python -m toir_manager report --base-dir logs/dispatch --json
```

## Формат имени входного файла

Имя отчета должно соответствовать шаблону:

```text
CT-DR-B-<part>-<object>-<TZ>-<period>-<date>-<revision>_All.pdf
```

Пример:

```text
CT-DR-B-CS-ES-II.2.6-00-C-20250812-02_All.pdf
```

Используйте в именах латинские символы (`A-Z`, `0-9`). При обнаружении кириллицы приложение пытается выполнить автоматическую транслитерацию. Если безопасное преобразование невозможно, аномалия записывается в журнал, а отчет пропускается.

## Схема обработки

1. Приложение рекурсивно ищет в `INBOX_DIR` проектные каталоги с `_All.pdf`.
2. Из имени извлекаются часть, объект, период, дата, ревизия и другие атрибуты.
3. Применяется выбранный фильтр `TOIR_PART_FILTER`.
4. Включенные копии записываются в NOTES, TRA_GST, TRA_SUB_APP и `DEST_ROOT_DIR/pdf`.
5. ZIP-архив проектного каталога создается и копируется в `DEST_ROOT_DIR/Native`.
6. Каждое действие записывается в `logs/dispatch/<run_id>.jsonl`.

В одном проектном каталоге должен находиться только один `_All.pdf`. Если подходящих файлов несколько, обрабатывается только первый.

## Каталоги и переменные окружения

| Переменная | Назначение |
| --- | --- |
| `TOIR_INBOX_DIR` | Входной каталог. Проектом считается папка, в которой найден `_All.pdf`. |
| `TOIR_NOTES_DIR` | Каталог копий отчетов для примечаний. |
| `TOIR_TRA_GST_DIR` | Недельная структура с каталогами `YYYY_TWW_GST`. |
| `TOIR_TRA_SUB_APP_DIR` | Дополнительная группировка по `<tz_index>-<reserved>-<period>`. |
| `TOIR_DEST_ROOT_DIR` | Корень итоговой структуры `Год/Месяц/Part/{pdf,Native}`. |
| `TOIR_TEMP_ARCHIVE_DIR` | Временный каталог для создания ZIP-архивов. |
| `TOIR_DISPATCH_DIR` | Каталог журналов JSONL. UI задает его автоматически. |
| `TOIR_PART_FILTER` | Фильтр части: `LP`, `CS` или `CS/LP`. Некорректное значение заменяется на `CS/LP`. |
| `TOIR_ENABLE_NOTES` | Включает или отключает распределение в NOTES. |
| `TOIR_ENABLE_TRA_GST` | Включает или отключает распределение в TRA_GST. |
| `TOIR_ENABLE_TRA_SUB_APP` | Включает или отключает распределение в TRA_SUB_APP. |
| `TOIR_ENABLE_DEST_ROOT` | Включает или отключает итоговое распределение PDF/Native. |
| `APP_HEADLESS` | Значение `1` запрещает запуск графического интерфейса. |

Настройки UI хранятся в `~/.toir_manager/ui_paths.json`. В Windows это обычно `%USERPROFILE%\.toir_manager\ui_paths.json`.

## Правила назначения

- `TRA_GST_DIR` использует каталоги по ISO-неделям. Если ожидаемая папка уже содержит архив, приложение выбирает следующую свободную неделю.
- `TRA_SUB_APP_DIR` при необходимости использует `Template/TZ_glob.xlsx` для поиска суффикса.
- `DEST_ROOT_DIR` формирует структуру `Год/Месяц/<part>/{pdf,Native}`.
- Период `C` или кириллический `С` направляется в существующий бизнес-каталог `Корректирующее обслуживание`.
- В суффиксах объектов LP удаляются ведущие нули, например `BVS05` преобразуется в `BVS5`.
- Каталоги CS выбираются по настроенным префиксам, например `CS_FOLDER_OVERRIDES`; отсутствующие `pdf` и `Native` создаются автоматически.

## Журналы

Каждый запуск создает файл `logs/dispatch/<run_id>.jsonl`. Вкладка Logs настольного интерфейса показывает записи в таблице. CLI формирует текстовую или JSON-сводку.

Настольный интерфейс также позволяет:

- открывать выбранный или все целевые каталоги;
- удалять все журналы, кроме последнего;
- после подтверждения удалять из INBOX успешно обработанные проектные папки;
- просматривать stdout, предупреждения и ошибки текущего запуска.

## Сборка EXE для Windows

Установите PyInstaller в активное виртуальное окружение и используйте готовую спецификацию:

```powershell
python -m pip install pyinstaller
pyinstaller ToirManager.spec --noconfirm
```

Исполняемый файл создается по адресу `dist/toir_raspredelenije.exe`. Двойной щелчок открывает настольный интерфейс. Запуск конвейера без UI:

```powershell
.\dist\toir_raspredelenije.exe --run-pipeline
```

В собранном приложении журналы распределения создаются в `dist/logs/dispatch`.

## Структура проекта

```text
repo/
|- toir_raspredelenije.py      # конвейер распределения
|- run_ui.py                   # точка входа настольного приложения
|- ToirManager.spec            # конфигурация PyInstaller
|- src/toir_manager/
|  |- core/                    # модели домена и журналирования
|  |- services/                # настройки и ввод-вывод журналов
|  |- cli/                     # консольные отчеты
|  |- ui/                      # интерфейс Tkinter и переводы
|- tests/                      # набор pytest
|- Template/                   # справочник и шаблоны
|- logs/dispatch/              # журналы запусков JSONL
|- assets/                     # иконка и снимки интерфейса
```
